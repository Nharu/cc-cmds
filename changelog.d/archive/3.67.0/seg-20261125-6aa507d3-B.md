등급: minor

인자 없이 부른 `scripts/test-gate.sh` 가 더는 직렬 전량을 돌지 않고, 기준점 대비 바뀐 축의 절만 골라 돕니다. 전량은 `--full` 을 줄 때만 돌고, 무인 런에서는 그마저 거절되며, 대화형 세션에서는 새 PreToolUse 훅이 사람의 승인을 묻습니다. 모르는 절 id·구역 표시 없는 사본·맨 `--timing-table` 처럼 조용히 전량으로 떨어지던 갈래는 모두 종료 2 로 멈춥니다.

### Added

- **`--changed`·`--full` 인자** — 인자 없는 호출은 `--changed` 와 같아 `scripts/gate-select.sh` 로 작업 트리 스냅샷의 바뀐 축을 고르고, 고른 절이 없으면 종료 0, 고르지 못하면 종료 2 로 끝납니다. `--changed --estimate` 는 고른 절의 예상만 냅니다. 기준점은 `CC_GATE_SELECT_BASE`, 없으면 `make check` 의 프로브와 같은 규칙으로 잡습니다.
- **test-gate 전량 승인 훅** — `plugins/cc-cmds/hooks/test-gate-full-pretool.sh` 가 `test-gate.sh` 뒤에 `--full` 이 오는 Bash 명령에 `ask` 를 냅니다. `CC_PIPELINE_RUN_ID` 가 있는 무인 스테이지에서는 비킵니다.
- **절 시작 줄과 순번** — 좁힌 실행이 절마다 `절 시작 — <id> · k/n번째` 줄을 찍고, 진행 줄에도 순번이 붙습니다.

### Changed

- **전량으로 떨어지던 갈래의 멈춤** — `--sections` 의 모르는 id(직접 지명이나 `needs:`), 구역 표시를 찾지 못한 사본, 맨 `--timing-table`, 빈 `--sections` 는 절을 돌리지 않고 종료 2 로 끝납니다.
- **무인 런의 전량 거절 위치** — `make check` 의 `check-unattended-refusal` 을 거두고, 무인 런의 `--full` 거절을 `scripts/test-gate.sh` 자신이 맡습니다. `make check` 는 자기 프로브가 찾은 merge-base 를 `CC_GATE_SELECT_BASE` 로 넘깁니다.
- **종료 절 정산과 킥오프 제안** — 킥오프의 사전 인가 제안 예시가 `bash scripts/test-gate.sh --sections` 가 되고, 라우팅 교대는 그 형태에 묶인 종료 절의 절 id 를 머지된 변경에 선택기를 돌려 고릅니다. 예전 형태 행은 머지의 첫 부모를 기준점으로 주고, 절을 하나도 돌리지 않은 통과는 근거로 읽지 않습니다.
