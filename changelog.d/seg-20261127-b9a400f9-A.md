등급: patch

라우팅된 무인 런에서 재수렴 스테이지와 설계 감사 스테이지가 `doc-tidy.py checkout` 으로 임시 디렉터리에 만든 설계 문서 작업 사본을 Read 하지 못해 세그먼트가 런 끝까지 막히던 결함을 고친다. 두 스테이지의 설정 변종만 그 런의 작업 사본 이름 공간을 Read·Edit 할 수 있게 되고, 다른 런의 사본과 같은 호스트의 다른 임시 파일은 그대로 닫혀 있다.

### Fixed

- **재수렴·설계 감사 스테이지의 작업 사본 권한** — 게이트가 렌더하는 `reconverge`·`audit` 설정 변종의 `permissions.allow` 에 `Read(/<TMPDIR>/cc-proto-<런 id>-*/**)` 와 `Edit(/<TMPDIR>/cc-proto-<런 id>-*/**)` 두 규칙을 더한다. TMPDIR 은 `doc-tidy.py` 가 사본 경로를 만들 때와 같은 철자(끝의 `/` 만 뗀 값)로 쓰고 물리 경로로 풀지 않는다. 철자나 런 id 가 절대 경로가 아니거나 비었거나 glob 메타 문자·역슬래시·제어 문자를 담으면 규칙을 쓰지 않고 경고 한 줄만 남긴다. `additionalDirectories` 와 다른 변종의 allow 는 바뀌지 않는다.
- **설정 재유도 키** — TMPDIR 철자를 키 입력에 더해, 다른 TMPDIR 로 연 게이트가 옛 철자의 규칙을 남겨 두지 않고 설정을 다시 렌더한다.
