등급: minor

원격 답 모드가 선택지뿐 아니라 텍스트 답도 세션에 넣습니다. 텍스트 능력으로 등록한 발신자는 열린 AskUserQuestion 과 질문지의 기타 입력·자유 입력 질문에 텍스트로 답할 수 있고, 차례를 넘기고 쉬고 있는 세션에는 새 지시를 보낼 수 있습니다. 원격에서 들어온 입력은 `[cc-cmds 원격 입력] 발신=<발신자>` 표지 줄로 전사에 구별되어 남습니다.

### Added

- **텍스트 봉투 적용** — 이음매가 `kind: "text"` 봉투를 받습니다. 사건의 `accepts` 와 발신자의 `capabilities` 가 모두 `text` 를 담을 때만 받으며, 텍스트는 공백만이 아니고 4000 코드 포인트 이하이며 제어 문자가 없어야 합니다(차례 넘김 텍스트만 탭과 줄바꿈 허용). 질문지 답 머리 줄을 담은 텍스트는 받지 않습니다.
- **AskUserQuestion 텍스트 답** — 단일 선택은 텍스트가 답 문자열이 되고, 다중 선택은 고른 라벨 뒤에 `, ` 로 텍스트를 잇습니다. 새 사후 도구 훅 `remote-reply/posttool.sh` 가 그 호출 뒤에 표지 줄을 추가 맥락으로 남깁니다.
- **질문지 텍스트 답** — 자유 입력 질문과 기타 입력을 받는 단일 선택 질문에 텍스트를 넣고 제출하며, 제출 묶음 끝에 표지 줄을 붙입니다.
- **새 지시** — 런을 돌리지 않는 세션이 차례를 넘기고 쉬는 동안(차례가 돌지 않고 마지막 사람 입력에서 45초가 지남) 그 차례 넘김 사건 뒤에 사람 입력이 없었으면, 표지 줄과 지시 텍스트를 사람의 말로 제출합니다. 이음매 하위 명령 `turn-pick`·`turn-record`·`turn-unpick`·`mark-take` 가 더해졌습니다.
- **시험** — `scripts/test-remote-free-text.sh` 와 고정 예제 `tests/fixtures/remote-free-text/` 를 더했고, 봉투 규칙 린트가 `--text-fixtures` 로 텍스트 봉투를 검사합니다.

### Changed

- **귀환 훅** — 첫 줄이 원격 입력 표지 줄인 프롬프트는 사람이 돌아온 것으로 읽지 않아 배너를 내리지 않습니다.
- **원격 답 모드의 사람 입력 판정** — 첫 줄이 원격 입력 표지 줄인 프롬프트는 사람 입력 시각을 바꾸지 않습니다.
- **질문지 답 대상** — 원격 답 대상의 질문 항목이 `kind` 와 `allow_other` 를 싣습니다.

### Post-install notes

- 텍스트 답을 쓰려면 `~/.config/cc-cmds/remote-senders.json` 의 그 발신자 `capabilities` 에 `"text"` 를 더해야 합니다. 선택지만 등록된 발신자는 지금처럼 선택지 봉투만 받습니다.
- 머지 뒤 대화형 세션에서 사람이 확인할 것이 셋 남아 있습니다. 원격 텍스트로 이긴 AskUserQuestion 의 도구 결과가 같은 텍스트를 기타 입력에 친 결과와 같은 모양인지, 원격으로 이긴 AskUserQuestion 호출 뒤에도 사후 도구 훅이 돌아 표지 줄이 도구 결과와 다른 항목으로 한 번 남는지, 새 지시가 플러그인 틀 없이 표지 줄로 시작해 전사에 남고 모드 자신의 제출이 사람 입력으로 세어지지 않는지입니다.
