# 리뷰 게시 문면 — 기본

`gate.sh act --kind review-post` 가 PR 에 올리는 리뷰의 글을 이 파일의 틀에서 만든다. 렌더러는 `review-post.sh` 다.

- 틀은 `## <틀 이름>` 머리 바로 아래의 첫 펜스 블록 하나다. 펜스 안의 바이트가 틀이고, 펜스 밖의 글은 읽지 않는다.
- 틀 이름은 여섯 개로 닫혀 있다: `본문`, `본문 지적 없음`, `본문 지적`, `코멘트`, `헤드 변경`, `정산 본문`.
- 자리표시자도 닫혀 있다: `{등급}` `{제목}` `{근거}` `{제안}` `{파일}` `{줄}` `{P0}` `{P1}` `{고정 헤드}` `{현재 헤드}` `{지적 목록}`. 그 밖의 `{…}` 가 틀에 있으면 렌더러가 거절한다. 그 틀의 자리에서 값이 없는 자리표시자는 빈 문자열이 된다.
- 렌더러는 자리표시자만 값으로 바꾸고 다른 바이트는 그대로 둔다. 바꾼 값은 다시 읽지 않는다.
- 킥오프가 이 파일을 덮어쓰면, 덮어쓴 틀만 바꾼 사본을 런 디렉터리 옆(`docs/pipeline-run/<run id>.review-format.md`)에 두고 매니페스트의 `리뷰 문면` 행이 그 파일과 sha256 을 동결한다.

본문은 위에서부터 이렇게 모인다: PR 헤드가 리뷰한 커밋에서 움직였으면 `헤드 변경` 한 줄, 그다음 P0·P1 지적이 있으면 `본문`, 없으면 `본문 지적 없음`, 그다음 인라인으로 걸 수 없는 지적마다 `본문 지적`. 조각 사이는 빈 줄 하나다. 인라인으로 걸리는 지적은 `코멘트` 틀로 그 줄에 붙는다.

## 본문

```text
자동 리뷰 결과를 올립니다. P0 {P0}건, P1 {P1}건입니다.

리뷰한 커밋은 {고정 헤드} 입니다. 줄에 걸 수 있는 지적은 그 줄에, 걸 수 없는 지적은 아래에 적었습니다.
```

## 본문 지적 없음

```text
자동 리뷰에서 P0·P1 지적이 나오지 않았습니다.

리뷰한 커밋은 {고정 헤드} 입니다.
```

## 본문 지적

```text
**{등급}. {제목}**

위치 {파일} · 줄 {줄}

**근거**

{근거}

**제안**

{제안}
```

## 코멘트

```text
**{등급}. {제목}**

**근거**

{근거}

**제안**

{제안}
```

## 헤드 변경

```text
리뷰한 커밋은 {고정 헤드} 이고, 게시하는 시점의 PR 헤드는 {현재 헤드} 입니다. 그 사이의 변경은 이 리뷰에 들어 있지 않습니다.
```

## 정산 본문

```text
종료 절 정산 리뷰입니다. 리뷰한 커밋 {고정 헤드} 의 P0 {P0}건, P1 {P1}건입니다.

{지적 목록}
```
